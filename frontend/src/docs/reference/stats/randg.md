# randg

Gaussian (normal) random number


## Syntax

```
randg(mu, sigma)
```

## Description

Gaussian (normal) random number

## Mathematical Formulation

$$ X \sim \mathcal{N}(\mu, \sigma^2) $$

## Input Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `mu` | Number | Yes | Dynamic viscosity [Pa·s]. |
| `sigma` | Number | Yes | Surface tension [N/m]. |
