    **Final-residual guard.** A solve whose assembled solution leaves any equation's residual above `max(1e-6, 100·rel_tolerance)`, relative to that equation's own top-level terms, now fails with the equation quoted instead of reporting `ok` (`engine::unconverged_equation`, applied in `PreparedDocument::assemble_solution` for solve, sweep rows and all-roots). This is the path by which the merge rescue once returned a 1.2e4 residual as success. Across the 843 converged corpus solves the worst relative residual is 1.3e-7, so no golden changes.

    **DYNAMIC unit check (2026-10-22).** `DYNAMIC` bodies and their scalar initial conditions now reach the unit checker in `check`, the prepared solve and the ODE-only shortcut, through one helper (`engine::unit_check`).
    - `der(X)` carries X's units per second when X has real units. For a dimensionless state, whose model is unitless, it stays a wildcard.
    - A bare-number initial value (`x(0) = 0`) declares nothing.
    - The time variable is a wildcard.
    - `If(...)` now carries its branch units instead of reading as dimensionless.
    - Method-of-lines `FOR` blocks and array-state initials are checked too (2026-10-23, see the fifth paragraph below).

    The check exposed one library defect. SigPID's clamped anti-windup was `der(ie) = e + (out.sig - u_raw)/Taw`, which balances only with Taw in output-per-measurement units. It is now `/(Ki·Taw)`, so Taw is a reset time in seconds (owner decision 2026-10-22). Every affected example states `Taw = old/Ki`, so results are unchanged. `ev-battery-cooling-pid`'s input changed with provenance, and its expected output did not. It also exposed bare component parameters in 2 Help examples, 4 reference pages and 2 gallery models, which now carry units.

    **Component parameter units (2026-10-22).** A component header's `Resistor(R [ohm])` unit now reaches `components::def::Param`. A bare instance value under it is typed for the checker (`R=10` is 10 Ω), never scaled. 255 parameters of 105 components in `library-data/` declare the units their reference pages stated. `parse-library.mjs` reads them, so the header is the wizard's unit source, and the generated catalogs did not change. No example warned. One test had pinned the Java engine's false "right side [A]" warning on an untyped resistor; it now asserts none.

    **Table and plot checklist audit (2026-10-23).** The September reviews (T1–T15, F1–F12; recovered from `0b116de^:docs/`) were walked item by item against the code, not test titles. All fifteen table items and eleven of the twelve plot items were already fixed and pinned by a test, mostly in `tables.precision.test.ts`, `tableValidation.test.ts`, `tableGridModel.test.ts`, `csv.test.ts`, `composeTables.test.ts`, `solve_table.rs` and the `plots/` suites.     **Method-of-lines unit check (2026-10-23).** `FOR` blocks inside `DYNAMIC` and array-state initials (`T[2](0) = T_init`, `T[1:N](0) = …`) now reach `engine::unit_check`. Loop bounds such as `N` are solved values, unknown at check time, so each loop body is lowered once rather than expanded (`MolArrays`). An array indexed anywhere by something other than a literal is one field and reads as a single variable, so the boundary `T[1] = T_left` and the initials ground the loop body. An array indexed only by literals keeps one variable per element, because a state vector may mix position and velocity. A loop variable reads as a dimensionless 1. Pinned by `method_of_lines_bodies_and_array_initials_are_unit_checked`; all 809 doc blocks still check at zero unit warnings.

    **Component parameter descriptions and units (2026-10-23).** The 162 component pages with two-column parameter tables now have three, each parameter described from the component's own equations, and their library headers declare the units: 489 newly typed parameters, dimensionless ones as `[-]`. All 809 doc blocks check at zero unit warnings, and the regenerated catalogs only gain units and descriptions.

### Standing rules from closed programmes

These bind any further work that draws on the same sources.

**Licence rule (binding on every phase).** CircuitJS is GPL-2.0-or-later (`COPYING.txt`, `README.md`, file headers).
- No CircuitJS code, translated code, constants taken from its source, icons, help text or example circuits enter frees.
- Every adopted item is a behaviour reimplemented from physics and frees' own architecture. Lessons, equations and test data cite their own sources.
- One study proposed copying CircuitJS's speed-slider formula. That is rejected; frees chooses its own log mapping.

**RustGIS (Apache-2.0) shell work.**
- **Patterns only.** No RustGIS code, icons, theme JSON, spacing scale or artwork enter frees. We reimplement behaviour with frees' existing React 19, Mantine, Tabler and dockview, so no attribution is owed.
- **Visual identity is frozen** (Doc A §5, Doc B §9.1). The following stay as they are: `primaryColor: 'teal'`, the dark default, `defaultRadius: 'md'`, the Cascadia Code stack, the teal.7 → cyan.6 Solve gradient (it doubles as the progress bar), the dockview retint to Mantine tokens, and every chart, CodeMirror and Glide palette. New chrome uses only existing tokens and existing Tabler icons. No new docking, chart or icon package is allowed.
- **Keep a route to every feature.** No phase removes a command until the command parity test shows it is reachable elsewhere. Old labels stay as search aliases.
- **Close and Delete are different actions.** Closing a view never deletes data, stops a run, discards an analysis draft, clears terminal history or loses a digitizer calibration.

## 4. Acceptance Gates

Every change must pass the following. Commands and current counts are in [`CLAUDE.md`](CLAUDE.md#essential-development-commands).

- **Rust:** `cargo fmt --all --check`; `cargo clippy -D warnings` on native and `wasm32-unknown-unknown`; `cargo test --workspace -- --skip golden_corpus_parity`; `cargo test --release --test parity`.
- **Goldens:** every fixture passes within [`fixtures/tolerances-rustprop.json`](fixtures/tolerances-rustprop.json). CI fails on an unused tolerance entry. Never edit a golden to fit a code change; a regenerated golden states its provenance in `oracle.generated_by`.
- **Frontend (Node 22):** `npm test`, `npm run lint`, `npm run check-docs`, `npm run check-examples` (zero unit warnings), and `npm run build` with PWA assets.
- **Bundle:** `frees.wasm` ≤ 5,120 KiB raw. CI warns at 200 KiB headroom (`ci.yml` ledger).
- **Language changes** must still satisfy the migration matrix:
  - Equation functions solve forward and backward.
  - Multi-output calls keep order, shape and units.
  - Discarded outputs keep their constraints.
  - Ordered bodies never read before assignment.
  - Repeated instances stay independent.
  - Tables called like functions interpolate identically.
  - Index/call/initial resolution is deterministic, including the index-0 diagnostic.
  - A defaulted input that is swept takes one value per row.
  - ODE/DAE/event/accessor tolerances hold.
  - An unknown variant selector is a preparation error.
  - Analysis settings reach CLI, WASM and UI identically.
  - Metadata, plot and check calls stay out of the balance count.
  - Legacy import round-trips.
