# r2

Linear-fit coefficient of determination R^2


## Syntax

```
r2(xvals, yvals)
```

## Description

Linear-fit coefficient of determination R^2

## Mathematical Formulation

$$ R^2 = 1 - \frac{\sum (y_i - \hat y_i)^2}{\sum (y_i - \bar y)^2} $$
